## 2. How it works (30-second version)

- Every task/goal/pref saves to browser `localStorage` immediately — the app works fully offline.
- Sync is opt-in. When signed in, the app reconciles the local cache with your PocketBase:
  push local changes → pull remote deletions → push/pull records by `updatedAt` (newer wins) → pull remaining changes.
- Deletes propagate via tombstone rows **and** the server record is removed, so a deleted task can't be resurrected by another device's stale copy.
- The browser talks to PocketBase through the app's **same origin** (`/pb` proxy, rewrites in `next.config.ts`), which satisfies the CSP and means phones/LAN devices need no per-device URL setup.
- The StepFun AI API key **never syncs** (stays per-device).

## 7. Known limitations (documented, acceptable)

- Daily snapshots are keyed by device-local date: devices in different timezones write separate
  snapshot rows for the same day (task/goal/prefs sync is unaffected).
- A directly-configured cross-origin PocketBase URL (Settings field, advanced) is outside the
  CSP allowlist and may be service-worker-cached — use the default same-origin `/pb` path.
- "Erase All Data" while offline re-arms tombstones that flush on the next sign-in/sync
  (other devices receive the deletion then).
